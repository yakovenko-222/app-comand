# Робочий простір (Командний додаток)

Сучасний додаток для управління задачами, планами, фінансами та виплатами команди.  
Повністю підготовлений для локального встановлення та роботи на ПК (Windows).

---

## 🚀 Швидке встановлення та запуск на ПК

### Спосіб 1: Автоматичне встановлення (В один клік)

1. Переконайтеся, що на ПК встановлено [Node.js](https://nodejs.org/) (версія 18 або новіша).
2. Запустіть файл **`install.bat`** подвійним кліком:
   - Він автоматично встановить `pnpm` (якщо ще не встановлено).
   - Завантажить та встановить усі бібліотеки.
   - Збере оптимізовану версію проєкту.
   - Створить красивий ярлик **«Робочий простір»** з іконкою прямо на вашому робочому столі!

---

## 🖥 Як користуватися додатком

- **Запуск через робочий стіл**: двічі клікніть на ярлик **«Робочий простір»** на робочому столі Windows. Додаток відкриється в чистому віконному режимі (без зайвих рамок і вкладок браузера, як нативна програма).
- **Запуск через консоль**: двічі клікніть на **`start-app.bat`** або виконайте в терміналі:
  ```bash
  pnpm start
  ```
- **Зупинка додатку**: двічі клікніть на **`stop-app.bat`**.

---

## 📱 Встановлення як PWA (Progressive Web App)

Додаток має повноцінний маніфест та іконки для PWA:
1. Запустіть додаток (відкриється адреса `http://localhost:3000`).
2. В адресному рядку браузера (Chrome або Edge) натисніть іконку **«Встановити додаток»** (значок комп'ютера зі стрілочкою праворуч в адресному рядку).
3. Додаток додасться до меню «Пуск» та панелі завдань Windows як автономна програма.

---

## 📱 Встановлення як повноцінний Android додаток (APK)

Додаток повністю налаштовано на платформі **Capacitor** для нативного середовища Android:

### ⚡ Швидкий спосіб отримати APK:

1. Двічі клікніть на файл **`open-android.bat`**:
   - Він автоматично оновить веб-збірку додатку та запустить **Android Studio** з готовим проєктом.
2. В Android Studio:
   - Дочекайтеся індексації та завантаження компонентів (Gradle Sync).
   - У верхньому меню перейдіть: **Build** ➔ **Build Bundle(s) / APK(s)** ➔ **Build APK(s)**.
   - За хвилину у правому нижньому кутку з'явиться сповіщення з посиланням **«locate»**.
3. Натисніть **«locate»** — відкриється папка з готовим файлом **`app-debug.apk`**.
4. Скиньте файл **`app-debug.apk`** на телефон через Telegram / USB / Google Диск та натисніть «Встановити». Додаток встановиться як звичайний повноцінний мобільний застосунок!

## 🛠 Структура скриптів

### Для комп'ютера (Windows):
- **`install.bat`** — Майстер автоматичного встановлення та налаштування проєкту на новому ПК.
- **`start-app.bat`** — Запуск сервера та вікна програми з відображенням логів.
- **`start-silent.vbs`** — Фоновий запуск без чорного вікна командного рядка (використовується ярликом).
- **`stop-app.bat`** — Швидка зупинка фонового сервера додатку.
- **`server.js`** — Вбудований автономний сервер без сторонніх залежностей, що обслуговує статичну збірку `out/`.
- **`scripts/create-shortcut.ps1`** — Створення ярлика з кастомною іконкою на робочому столі Windows.
- **`scripts/start-app.js`** — Автоматичне відкриття віконного режиму через Edge/Chrome.

### Для Android (APK):
- **`open-android.bat`** — Автоматична синхронізація коду та відкриття проєкту в Android Studio з коректним JDK.
- **`build-apk.bat`** — Запуск компіляції APK файлу.
- **`android/`** — Повний нативний Android проєкт (Gradle, AndroidManifest, іконки, ресурси).
- **`capacitor.config.json`** — Конфігурація нативного додатку (ідентифікатор `com.workspace.app`, назва `Робочий простір`).
